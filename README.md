# Playwright Python Automation

> This project is still on-going.

A hands-on test automation project built with Python, Playwright, and pytest.

This project is being developed as part of my learning journey in E2E test automation, with a focus on building maintainable and reusable automated tests.

Website that is being tested: https://opensource-demo.orangehrmlive.com/

## 🛠️ Tech Stack
- **Language:** Python
- **Automation:** Playwright
- **Framework:** pytest
- **Design Pattern:** Page Object Model
- **OS:** Linux Mint 22.2
